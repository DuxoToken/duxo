# DUXO

## Official Documentation & Technical Information

DUXO is a fixed-supply digital asset built on the **Solana blockchain** using the **SPL Token standard**.

The project focuses on scarcity, transparency, verifiable on-chain information, and a clearly documented token structure.

## Token Distribution

The total supply of 1,000 DUXO is structured as follows:

* **600 DUXO (60%)** — Market
* **200 DUXO (20%)** — Founder
* **200 DUXO (20%)** — Community

The distribution is documented as part of the project's public documentation.

---

## Transparency

DUXO is designed around a fixed and verifiable token structure.

Key characteristics include:

* Fixed maximum supply of 1,000 DUXO
* 0 decimals
* Revoked Mint Authority
* Publicly verifiable on-chain token information
* Public project documentation
* Transparent token distribution

DUXO does not claim to have proprietary smart-contract code beyond the standard Solana SPL Token infrastructure used to create and operate the token.
